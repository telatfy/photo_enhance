
# Photo Restorer AI - Full App

## How to get APK in 3 minutes (No Android Studio needed):
1. Create free account on github.com
2. Create new repository, upload this whole folder
3. Go to Actions tab -> Click Build APK -> Download artifact -> You get app-debug.apk

## Or build locally:
1. Open in Android Studio
2. Replace BASE_URL in MainActivity.kt with your backend Render URL
3. Run -> Build APK

Backend: See /photo_restorer_backend folder
